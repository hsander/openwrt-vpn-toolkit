# openwrt-skill

**Управление роутером OpenWrt через ИИ** — настрой VPN и маршрутизацию,
безопасно перенеси домашнюю LAN в другую подсеть или собери travel router,
который подключается к Wi-Fi гостиницы и сохраняет приватную сеть и доступ домой.

> [English documentation →](./README.md)

---

## Что это такое

Ты открываешь этот проект в Claude Code и просто пишешь:

> *«Настрой VPN на домашнем роутере»*  
> *«YouTube перестал работать, почини»*  
> *«Сделай так, чтобы телевизор всегда ходил через американский сервер»*  
> *«Добавь Instagram в список обхода блокировок»*
> *«Сделай из роутера 001 роутер для путешествий и подключи его к точке телефона»*

Claude делает всё сам: подключается к роутеру по SSH, делает резервную копию, применяет изменение безопасно и откатывает назад автоматически, если что-то пошло не так.

## Для кого

- Жители России, Беларуси, Ирана, Китая, ОАЭ и других стран с блокировками
- Все, кому нужно чтобы **YouTube, Instagram, Telegram, Twitter** работали
- Те, кто хочет **VPN на уровне роутера** — все устройства дома защищены без установки приложений
- Путешественники, которым нужна одна доверенная Wi-Fi сеть в гостиницах и удалённый доступ в домашнюю LAN
- Разработчики и системные администраторы, управляющие роутерами на OpenWrt

**Знания сетевого администрирования не требуются.** Ты можешь не знать, что такое sing-box, VLESS, Reality, tproxy или nftables. Claude знает.

## Что работает из коробки

| Задача | Что делает Claude |
|--------|------------------|
| Разблокировать YouTube / Instagram / Twitter / Telegram | Маршрутизирует эти домены через VPN автоматически |
| VPN на весь роутер (все устройства защищены) | Устанавливает sing-box с tproxy — каждое устройство в Wi-Fi идёт через VPN |
| Прибить конкретное устройство к конкретному серверу | Например, телевизор всегда через американский сервер |
| Несколько VPN-серверов с автопереключением | Если один сервер упал, трафик мгновенно уходит на следующий |
| LAN-прокси (ручной VPN для отдельных приложений) | HTTP/SOCKS5-прокси порт для приложений с поддержкой прокси |
| Watchdog с алертами в Telegram | Получай уведомления если роутер потерял интернет или VPN сломался |
| Безопасные изменения конфига с авторолбэком | Каждое изменение снапшотится; если SSH отваливается после перезапуска — откат |
| Добавление/удаление доменов из списка VPN | Без перезапуска sing-box, горячая перезагрузка |
| Travel-router профиль | Создаёт необычную приватную LAN, две приватные точки, Travelmate и постоянный доступ к LuCI |
| Подключение к Wi-Fi гостиницы с телефона/планшета | Внешнюю сеть можно добавить или заменить в LuCI без ноутбука |
| Скрытая приватная Wi-Fi с физическим восстановлением | Короткое нажатие Wireless Pairing показывает MobileHub на 10 минут; повторное нажатие сразу скрывает |
| Связь дом ↔ travel router через AWG2 | Через туннель идёт только домашняя LAN, обычный интернет остаётся на локальном uplink |
| Безопасная миграция LAN-подсети | Использует prepare/cutover/confirm/rollback и recovery endpoints вместо разовой смены адреса |

Безопасный API начинает работу после установки OpenWrt. Прошивка поверх
заводской системы, восстановление загрузчика и model-specific rescue пока не
автоматизированы и не являются частью travel-router сценария.

## Travel router: подключение к новой Wi-Fi сети

1. Включите роутер. Если MobileHub скрыт, коротко нажмите физическую кнопку
   `Wireless Pairing`: обе точки станут видимыми на 10 минут.
2. Подключите телефон/планшет к MobileHub и откройте LuCI по travel-адресу роутера, например
   `http://172.27.1.1` для роутера 001 (или HTTPS, если он был настроен отдельно).
3. Откройте `Службы (Services) -> Travelmate`, запустите поиск, выберите Wi-Fi
   гостиницы или точку телефона, введите пароль и нажмите
   `Сохранить и применить (Save & Apply)`.
4. Если гостиница показывает страницу авторизации, оставайтесь в приватной
   сети роутера и откройте обычную HTTP-страницу, например
   `http://neverssl.com`, затем завершите вход.
5. Откройте обычный сайт. Сохранённый uplink будет подключаться автоматически
   после перезагрузки, а доступ в домашнюю LAN продолжит идти через AWG2.

Если MobileHub уже видим, повторное короткое нажатие Wireless Pairing сразу
скрывает обе точки. Скрытый SSID — только уменьшение заметности, а не защита;
реальную защиту обеспечивают WPA2 и пароль.

Для дальности выбирайте 2.4 ГГц, для скорости — 5 ГГц. Неизвестные открытые
сети не добавляются автоматически. Полный порядок настройки и проверок:
[`12-travel-router.md`](./.claude/skills/openwrt/runbooks/12-travel-router.md).

## Как это устроено (для любопытных)

```
Ты (чат) → Claude → скрипты bin/*.sh → SSH → роутер OpenWrt
                           ↓
                    snapshot перед изменением
                    валидация конфига
                    поэтапное применение
                    проверка доступности → авторолбэк если SSH пропал
                    обновление локальных файлов памяти
```

Обычные операции идут через скрипты в `bin/`: backup → validation → apply →
verify → обновление memory. Прямой SSH доступен только через журналируемый
escape hatch `raw-ssh.sh` после явного подтверждения пользователя. Если роутер
стал недоступен после staged restart, восстанавливается предыдущий snapshot.

Стек VPN:
- **sing-box** (VLESS + Reality) — сам VPN-туннель
- **tproxy + nftables** — перехватывает трафик на уровне роутера, ничего не нужно настраивать на устройствах
- **FakeIP DNS** — маршрутизирует домены в VPN без утечки DNS-запросов
- **zapret** (опционально) — обход DPI для особо упорных блокировок (Россия, Беларусь)

Travel-стек:
- **Travelmate + LuCI** — выбор и запоминание гостиничных Wi-Fi и точек телефона с планшета
- **Постоянная приватная точка** — устройства всегда подключаются к одному доверенному SSID
- **AmneziaWG 2 site-to-site** — управление роутером и доступ в домашнюю LAN через отдельный туннель
- **Split routing** — только домашняя LAN идёт через AWG2, обычный интернет использует локальный uplink

## Безопасность

- SSH-ключ генерируется отдельно для каждого роутера (`~/.ssh/openwrt_<alias>_ed25519`), не переиспользуется
- VPN-секреты (UUID, приватные ключи) хранятся **только на роутере** — никогда не пишутся в чат, файлы памяти или логи
- Снапшоты хранятся на роутере в `/etc/vpn-kit/snapshots/` (chmod 700, только root)
- `memory/routers.yaml` в .gitignore — IP-адреса твоих роутеров не попадут в репозиторий

### Если ноутбук украли

1. Смени TG_TOKEN у @BotFather — старый перестанет работать, watchdog'и замолчат
2. Смени UUID/Reality-ключи у VPN-провайдера — старые туннели не откроются
3. На каждом роутере: удали старый SSH-ключ из `authorized_keys`
   ```bash
   ssh root@<router-ip> "sed -i '/openwrt_<alias>/d' ~/.ssh/authorized_keys"
   ```
4. Восстанови навык: `bin/setup-ssh.sh --router <alias> --host ...` создаст новый ключ

## Структура проекта

```
.claude/skills/openwrt/
├── SKILL.md           # Инструкции для Claude — что и когда вызывать
├── bin/               # Безопасный API: атомарные операции (Claude вызывает только отсюда)
│   ├── doctor.sh      # 20-пунктовый чек-лист → state.md
│   ├── setup-ssh.sh   # Первичная настройка SSH-ключа
│   ├── install-vpn.sh # Полный VPN-bootstrap (парсит vless://)
│   ├── add-domain.sh  # Добавить домен в список обхода
│   ├── set-rule-set-outbound.sh # Переключить сервисный rule_set на другой outbound
│   ├── add-vpn.sh     # Добавить VPN-ноду
│   ├── pin-device.sh  # Прибить устройство к конкретному серверу
│   ├── add-ip.sh      # Добавить IP-маршрут
│   ├── backup-now.sh  # Ручной снапшот
│   ├── restore.sh     # Откат к снапшоту
│   ├── install-travelmate.sh       # Установка Travelmate и LuCI-приложения
│   ├── configure-travel-router.sh  # Приватная точка, уникальная LAN и split route
│   ├── configure-home-travel-route.sh # Обратный маршрут на домашнем роутере
│   ├── verify-travel-router.sh     # Сквозная и post-reboot проверка
│   └── ...
├── lib/               # Общие хелперы (source'ятся bin/, не вызываются напрямую)
├── memory/            # Состояние роутеров: routers.yaml + <alias>/*.md
├── runbooks/          # Пошаговые гайды под каждый сценарий
└── templates/         # Шаблоны конфигов sing-box
```
